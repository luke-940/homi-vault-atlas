# Semantic Space Renderer

## Intent

Atlas uses real 3D only where spatial discovery materially improves understanding: desktop Home and Explore. Observe, Flow, Time, Agency, Search, and mobile keep purpose-built analytical or Canvas siblings.

The renderer adopts real camera, geometry, depth, occlusion, picking, and focus transitions. It does not adopt a live force simulation, a graph-engine control playground, continuous motion, all-label display, or invented edges.

## Non-negotiable meaning

- Coordinates come from the deterministic `atlas.graph.v1` layout.
- Every knowledge line is an actual directed edge or an aggregate command carrying every constituent edge ID.
- Preview never changes layout, camera, URL, or global reducer state.
- Commit selection may move the camera and update the URL.
- Homi is a provenance beacon, never a knowledge metric node.
- MOC, Papers, and Signals remain first-order anchors.
- Node kind is shape, district is color, gravity is size and local light, and direction is an arrow.

## Visual grammar

- Warm graphite background and negative space remain visible through a transparent WebGL canvas.
- Materials are rough, restrained, and only slightly emissive.
- No glossy spheres, Saturn rings, chrome, bloom, environment map, particles, or decorative space objects.
- Districts are spatial anchors and labels, not giant planets or front-facing panels.
- Persistent labels are budgeted and depth-aware; the full graph remains available through the accessible DOM list.

## Runtime boundary

- Direct Three.js, no React Three Fiber and no force-graph runtime.
- Content-hashed lazy IIFE preserves `file://`, HTTP, and Pages.
- WebGL loads only above 820 px when data-saver is off and a context is available.
- Mobile, context loss, and unsupported devices use the existing Canvas2D renderer without losing focus or URL state.
- Rendering stops when idle or hidden, DPR is capped, and disposal must release the context.

## Promotion gate

Promote only when the same graph and semantic state produces:

- visibly stronger parallax, depth, occlusion, and spatial manipulation;
- exact factual relation highlighting;
- no hover-driven scene rebuild;
- no interaction instability;
- accessible semantic parity;
- bundle and Mac resource budgets within contract.
