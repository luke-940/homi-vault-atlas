## Renderer ownership

- One focal visualization instance is visible at a time
- Desktop and tablet primary renderer: direct Three.js
- Mobile and failure fallback: Canvas2D
- WebGL owns batched nodes, local halos, relation field, focus edges, arrowheads, and picking targets
- React owns Chrome, editorial rail, labels, controls, evidence, URL state, and accessibility DOM
- Only one primary renderer is mounted; fallback is absent while WebGL is ready
- Render-ready signal: first successful nonblank frame plus scene version
- DPR: desktop 1.5 maximum; mobile Canvas 2 maximum
- Context lifecycle: one context, resize observer, context-loss fallback, explicit dispose
- Static export: deterministic camera bookmark with reduced motion and final-state emphasis

## Visual encoding ledger

| Data or state | Visual channel | Range | Must not imply |
| --- | --- | --- | --- |
| domain | color + label | fixed token set | performance or ownership |
| node kind | geometry | restrained primitive family | hierarchy beyond kind |
| unique inbound | size + halo radius | sqrt scale | quality score |
| occurrences | edge opacity/thickness | log scale | unique source count |
| topology | position | deterministic build-time layout | live movement |
| preview | local light + dimming | ephemeral | committed navigation |
| focus | amber ring + exact relations | committed | current operational status |

Essential without hover: six domains, graph scale, snapshot caveat, selected lens, reset route.

## State and persistence

| State | URL | Storage | Restore |
| --- | --- | --- | --- |
| workspace | yes | none | strict codec with Home fallback |
| lens/scene | yes | none | alias migration then default |
| focus node | yes | none | invalid id clears focus with notice |
| path endpoints | yes | none | invalid pair clears path |
| preview | no | none | always null |
| orbit camera | no | session only | lens bookmark |
| reduced motion | no | platform preference | media query |

URL state overrides session camera. Committed navigation pushes history; lens refinements and invalid-state repair replace it.

## Interaction state machine

| State | Entered by | Visual response | Exit |
| --- | --- | --- | --- |
| default | route or reset | full field, bounded labels | preview or focus |
| preview | hover or keyboard focus | local neighbors bright | leave, blur, focus |
| focused | click, Enter, tap | exact incoming/outgoing, evidence | Escape, back, reset |
| path | two endpoints | directed shortest path only | Escape, back, clear |

- Orbit: pointer drag above 4px threshold
- Zoom: wheel or explicit buttons; clamped authored bounds
- Touch: tap selects; two-finger or controls zoom; one-finger page scroll is preserved on mobile
- Dense picking: Raycaster over batched instance targets; mobile uses spatial index
- Idle clock: no continuous render after controls settle
- Hidden tab: frames stop
- Reduced motion: immediate bookmark/focus changes and static relation state

## Performance

- One WebGL context and one scene
- Overview draw calls ≤20; focus ≤24
- Static buffers upload once per graph version
- Preview updates only narrow color/opacity attributes
- Public graph JSON ≤250KiB; Owner graph JSON ≤750KiB
- Interaction frame p95 ≤22ms at 1440×920, DPR 1.5
- WebGL chunk ≤240KiB gzip
- Mobile never downloads the WebGL chunk
- Failure mode: context loss or unsupported WebGL activates the Canvas sibling with the same semantic state

## Accessibility

- Complete keyboard-operable node and edge index outside the canvas
- Direct domain labels and selected-node evidence remain visible
- Screen-reader summary states node kind, domain, gravity, incoming, outgoing, and focus state
- Shape, label, and line treatment repeat domain and direction information beyond color
- Reduced motion and Canvas fallback preserve the same claim
