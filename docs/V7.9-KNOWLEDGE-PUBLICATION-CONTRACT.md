# v7.9 Knowledge Publication Contract

## Product purpose

Atlas is a knowledge Map, not a marketing landing page. The v7.8 spatial graph
is the orientation surface. A committed node selection must answer:

1. What is this?
2. Why does it matter to Homi?
3. What does it point to and what points to it?
4. Why do those directed relationships exist?
5. What source evidence can a reader inspect?

The one public edition is safe for both Homi colleagues and outside visitors.
There is no authenticated or hidden team edition.

## Publication unit

The compiler classifies every captured Markdown document and every non-empty
section. Document dispositions are `published_with_dossier` or `excluded`.
Section dispositions are `knowledge`, `maintenance`, `sensitive`, or
`unsupported`.

A release is eligible only when:

- each graph node has exactly one dossier;
- each dossier has exactly one Safe Source document;
- every claim has at least one evidence reference;
- every relationship explanation resolves to an actual graph edge and a
  section-aware link occurrence;
- all documents and non-empty sections are classified;
- `physical = published_with_dossier + excluded`;
- document and section `unclassified = 0`.

The Gate 1 vertical slice contains exactly five reviewed documents and is
explicitly `releaseEligible: false`. It proves the pipeline and UI; it is not a
partial Atlas release.

## Section-aware occurrence ledger

Raw whole-file regular expressions are not an admissible relationship source.
The build-only Markdown parser emits a deterministic occurrence ledger after
frontmatter, code, raw HTML, embeds, maintenance, sensitive, and unsupported
content have been classified.

Each published occurrence binds:

- source and target node IDs;
- actual graph edge ID;
- direction;
- source section ID and safe context block ID;
- occurrence count;
- publication status.

Graph aggregation, dossier relationship explanations, Flow stories, Observe
workbenches, and evidence links all consume this same ledger. They may not
reconstruct relationship meaning independently.

## Evidence and interpretation

`source_explicit` means the public source block directly supports the claim.
`atlas_builder_bounded` means Builder interpretation combines cited public
blocks without exceeding them.

No claim may infer quality, importance, success, ownership, recency, or current
status from graph degree, occurrence count, file modification time, or absence.
Historic sections remain visibly historic. Evidence gaps are stated as gaps.

## Safe Source Reader

The Reader is a build-time projection, never raw Markdown. Supported blocks are
heading, paragraph, list, table, blockquote/callout, code, approved image, and
safe wikilink. Frontmatter, scripts, raw HTML, unsafe embeds, maintenance
sections, sensitive blocks, internal paths, and operating records are removed.

Links to published nodes become Atlas links. Links to excluded targets become a
non-clickable `비공개 대상` marker. Reader pages identify themselves as
`운영·민감 section을 제외한 공개 안전 원문`.

## Shards and release boundary

The initial knowledge index contains only title, domain, one-line summary,
review status, and content-hashed shard paths. Dossier and Reader bodies load
only after committed selection. Search content loads only when Search opens.

The release publication pack binds graph, meaning, knowledge index, every
knowledge shard, search index, and their digests. A missing, stale, malformed,
unreviewed, or hash-mismatched shard blocks publication.
