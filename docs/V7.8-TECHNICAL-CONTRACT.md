# v7.8 Technical Contract

## Surface and data profile

- One primary WebGL scene is visible at a time on desktop Home or Explore.
- Desktop viewports: 1440x920, 1280x720, 1180x720, 1024x768, 768x1024.
- Mobile siblings: 390x844, 320x844, 844x390.
- Public graph target: hundreds of admitted nodes and their actual references.
- Owner graph target: the public source set plus deeper safe local evidence.
- Runtime updates are user-driven only; there is no live feed or runtime force.

## Renderer ownership

- React owns navigation, evidence, labels, accessibility, and committed URL state.
- Direct Three.js owns node, edge, halo, arrow, camera, and picking buffers.
- Canvas2D owns the mobile and WebGL-failure sibling.
- One typed graph index and one interaction controller serve all three surfaces.
- WebGL context count is one; DPR is capped at 1.5 and contexts are disposed.

## Interaction state

- Default: whole admitted graph and quiet actual reference field.
- Preview: local relation highlight only.
- Focus: URL commit, bounded camera move, exact incoming/outgoing.
- Lens: camera bookmark and emphasis without coordinate changes.
- Escape: previous semantic state and camera.
- Idle/hidden: render loop stopped.
- Reduced motion: immediate camera and static relation state.

## Mobile

- WebGL is not loaded at `<=820px`.
- Initial view shows a domain mini-map and focused evidence before controls.
- Filters and details use a bottom sheet; closing restores graph focus.
- Primary targets are at least 44px.
- Search keyboard cannot cover the only close/apply action.

## URL

Canonical committed parameters are `workspace`, `lens`, `focus`, `from`, `to`,
`view=graph|structure|list`, and profile-safe filters. Preview, camera drag, raw paths, and owner-only data
never enter the URL. Invalid or legacy v7.5-v7.7 scenes recover to Whole Vault
with a visible notice.

## Directory hierarchy

`atlas.graph.v2.structure` carries the compact `atlas.directory.v1` hierarchy.
Folder rows contain stable opaque IDs, safe display labels, parent indexes,
domain indexes, depth, and direct graph-node indexes. Raw paths never enter
runtime bytes. Every admitted graph node is reconciled as represented once or
omitted from the directory with a counted reason. The Structure view is DOM
owned, keyboard operable, collapsed by default, and shares committed `focus`
with Graph and List.

## Performance and fallback

- Public graph JSON: 250 KiB raw maximum.
- Owner graph JSON: 750 KiB raw maximum.
- Shell: 180 KiB gzip; 3D chunk: 240 KiB; combined JS: 400 KiB.
- CSS: 44 KiB target and 48 KiB hard gate.
- Draw calls: 20 overview and 24 focus.
- Interaction frame p95: 22ms at 1440x920, DPR 1.5.
- WebGL loss preserves URL/focus and activates the Canvas sibling.
- Local QA is serial and stops at 1.5 GB RSS, 2 GB free memory, 250% CPU for
  10 seconds, thermal pressure, or 12 minutes.
