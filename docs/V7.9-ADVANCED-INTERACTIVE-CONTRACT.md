# v7.9 Advanced Interactive Contract

## Visual lock

The approved v7.8 Homi Vault stage is the visual reference. Its v7.9 visible
label is `Homi Vault`; the stable scene ID remains `whole-vault`. v7.9 changes the
information architecture around it, not its authored space. Comparison evidence
uses the same viewport, lens, focus, profile, and camera.

Flexible surfaces are Map Console copy density, dossier dock, Reader,
workbench, and Search result layout. Locked surfaces are graph coordinates,
domain colors, warm graphite field, node grammar, light, camera bookmarks,
Three.js picking, and mobile graph sibling.

## Map Console

The initial Home rail is an instrument panel:

- `Homi Vault`;
- snapshot date and node/edge/domain counts;
- compact Search;
- four existing lenses;
- Domain and node-kind facets that highlight the fixed graph without moving it;
- title search and a scrollable list of every admitted node;
- coverage ledger.

It contains no marketing eyebrow, oversized sales headline, long value
proposition, or CTA that implies Home is not already the Map.

The Map Index is the default rail body. Pointer or keyboard preview illuminates
the existing node and actual directed neighbors without loading a shard or
changing the URL. Click, Enter, or tap commits the shared focus and replaces the
index with the dossier. Domain and kind facets are local appearance state:
camera, graph coordinates, persistent label packing, and semantic history stay
byte-for-byte stable. Text search filters only the index until a result is
committed. Explore keeps its `Graph · Structure · List` analysis views and
shares the same focus identity; the Home index remains the immediate Map
navigation surface rather than replacing those deeper views.

On desktop the rail is presentation-only and resizable from 360–560px by
pointer or keyboard. Resizing may not mutate route, focus, camera, graph
coordinates, or dossier identity. Narrower layouts use an authored stack or
mobile sibling and intentionally disable resizing.

Preview leave/blur restores the committed node. Dossier tab changes never move
the camera or graph. Default Home starts with no committed selection and one
central label per domain. A visible `선택 해제` control beside every dossier

Graph labels show titles only. Direction, domain, and relation counts stay in
the evidence rail or dossier. Explore, Observe, Flow, Time, and Agency use a
single-line workspace tool bar; they do not place explanatory sentences as
page-scale headlines above the working surface.

## Dossier dock

Desktop uses the existing rail or a plot-external inspector. Compact desktop may
use a controlled overlay. Mobile uses a bottom sheet. No floating card may cover
the focal graph.

- Overview: summary, up to five insights, why it matters, caveats.
- Relations: up to six incoming and six outgoing explanations with direction.
- Evidence: excerpts, interpretation label, and Reader entry.

Every unavailable state is explicit: unreviewed Gate 1 node, evidence gap,
missing shard, digest mismatch, or removed source section.

## Reader

The Reader is DOM-first, Korean-readable, keyboard navigable, and visually
subordinate to source content. It preserves heading hierarchy, lists, tables,
callouts, code, and approved figures. It exposes a direct return to the exact Map
state and exact Atlas links for published wikilinks.

## Observe workbench

Global Relations remains the entry matrix. Node, relation, and evidence modes
answer different questions:

- Node: what this node says, why it matters, caveats, evidence.
- Relation: source to target direction, occurrence contexts, reverse relation,
  common neighbors, and separate bridge paths.
- Evidence: exact claim or relationship evidence plus Reader section.

A bridge is never styled or worded as a direct edge.

All four modes are directly enterable and create distinct data-bound DOM.
Missing input resolves to a deterministic reviewed default or an explicit
evidence-gap state; it never silently returns the user to Global Relations.

## Responsive and accessibility

- 1440/1280: persistent rail or fixed plot-external dossier.
- 1180/1024/768: compact rail or overlay that keeps the plot center visible.
- 390/320/844x390: Canvas2D graph then bottom sheet or full Reader.
- Essential targets are 44px on touch.
- Dossier, relation direction, evidence interpretation, and Reader links have
  complete accessible names.
- Reduced motion removes camera interpolation without changing information.
