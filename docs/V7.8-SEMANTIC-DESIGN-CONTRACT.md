- The graph remains visible while controls or details are open
- No opaque floating inspector may cover the focal graph

## Locked visual hierarchy

- Background: warm graphite with restrained aubergine depth
- Selection: one Homi amber accent
- Domain identity: mature domain colors with shape and label redundancy
- Node size and local halo: unique inbound documents
- Position: resolved reference topology and domain structure
- Edge thickness: occurrence count
- Arrowheads: local focus and path only
- Far: complete node and relation field plus domain silhouettes
- Mid: hubs, cross-domain bridges, and protagonist candidates
- Near: actual titles and local incoming/outgoing direction
- Label budgets: desktop 20, compact 14, mobile 8

## Interaction contract

- Hover and keyboard focus update ephemeral preview only
- Click, Enter, or tap commits focus and URL
- Pointer leave or blur restores committed selection
- Drag threshold prevents accidental click
- Empty-stage click clears preview but does not erase semantic history
- Escape restores the previous committed semantic state
- Orbit and zoom never change layout coordinates
- Lens changes use fixed camera bookmarks over the same coordinates
- Reduced motion uses immediate camera changes and static local relationship emphasis

## Motion

- Explanatory verbs: settle, reveal, focus, trace
- First frame: complete static field and readable headline
- Settle: field → domain identity → strongest factual cross-domain routes, once
- Focus: camera and emphasis transition, 420–560ms
- Trace: selected directed relation once, then static arrowheads
- Infinite motion, decorative particles, auto-rotation, and idle pulse are forbidden

## Mobile continuation

- Mobile uses a sibling Canvas2D presentation over the same graph/index and committed state
- It does not load the WebGL chunk at ≤820px
- Tap replaces hover; selected evidence appears in a bottom sheet or integrated evidence strip
- Primary touch targets are 44px or larger
- One-finger page scrolling remains native; explicit controls or two-finger gestures own graph zoom
- Search keyboard opening must leave a visible return path to the graph
- The local static snapshot has no remote stale/offline state; file-load failure produces an explicit fallback

## Editable, data-bound layers

- All node geometry, colors, sizes, labels, domains, counts, edges, camera bounds, and evidence text
- Lens emphasis, selection, relationship direction, and accessible summaries
- No data label or metric is baked into a generated image

## Flexible implementation details

- Exact token values, grid gaps, type scale interpolation, renderer geometry, and breakpoint mechanics
- Minor camera distance adjustments that preserve the approved framing
- Label collision resolution that preserves the label budgets and domain coverage

## Forbidden deviations

- Large planets, glossy spheres, Saturn rings, glass cards, neon cyberpunk, generic particles, or flat bubble maps
- OpenAI or another company used as the overall center
- Homi connected to knowledge with a synthetic edge
- Hiding Rocket, Groot, or Intelligence Layer after admission
- A sparse default field that recreates the v7.7 failure
- A desktop DOM merely stacked and scaled down for mobile
