# Homi Vault Atlas v7.9 working contract

Before every task, read `DESIGN.md`, `ARCHITECTURE.md`,
`docs/ATLAS-PRODUCT-CONTRACT.md`,
`docs/V7.9-KNOWLEDGE-PUBLICATION-CONTRACT.md`,
`docs/V7.9-TECHNICAL-CONTRACT.md`,
`docs/V7.9-ADVANCED-INTERACTIVE-CONTRACT.md`,
`docs/V7.9-VISUALIZATION-INVENTORY.md`, and the current Gate packet under the
local `REL-ATLAS-V7-9-20260729-01` evidence root.

This is a commercial knowledge product, not an MVP, demo, prototype, or visual
experiment. v7.9 turns the approved v7.8 spatial stage into a useful Map without
redesigning it. Every new production module or selector must replace and remove
an older responsibility recorded in `docs/replacement-ledger.json`.
`npm run architecture` must pass before product QA; current-test correctness
does not excuse concentrated complexity, duplicate responsibility, or
ever-growing feature modules.

The default surface is one truthful three-dimensional Vault graph with four
camera lenses: Homi Vault, Knowledge Core, Project Frontiers, and Agent
Stewardship. MOC, Papers, Signals, Rocket, Groot, and Intelligence Layer are
first-order public domains. An admitted public node keeps its actual safe title;
unsafe nodes are excluded with a reason rather than masked.

Every knowledge line is an actual directed reference. Position is derived from
link topology and domain structure, never file date. Homi is a provenance beacon
and has no knowledge gravity or synthetic edge. Preview is transient and local;
only committed selection changes the URL or camera.

Every published graph node must have one evidence-bound dossier and one
public-safe source document. Claims, relationship explanations, and Reader
sections are compiled from the same section-aware link-occurrence ledger.
Unreviewed nodes are excluded from a release; the five-node Gate 1 slice is a
non-release proof and may never be promoted as a partial public release.

Do not modify Luke Vault, Notion, `graph.json`, Current State, Batch/cursor,
Daily, Rocket, Groot, or HIL. Do not publish Owner bytes, document bodies,
internal paths, PII, secrets, receipts, command history, or live operating state.
Stop on torn capture, reconciliation failure, unsupported claims, synthetic
relations, public/private crossover, unsafe Reader content, default-view
hairball, interaction instability, resource limits, or production readback
failure.
